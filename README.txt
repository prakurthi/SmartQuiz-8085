# SmartQuiz – 8085 Quiz Buzzer System

A quiz buzzer project based on the 8085 microprocessor concept, featuring an interactive web interface.

## Live Website

https://stellular-pie-634985.netlify.app

## Project Files

* `index.html` – Website structure
* `style.css` – UI design
* `script.js` – Quiz functionality
* `quiz_buzzer.asm` – 8085 assembly program

## Technologies

* HTML
* CSS
* JavaScript
* 8085 Assembly Language
